# 邀请一起做

下面这段可以用于自己的公众号、社交账号或开发者社区。发布前按渠道长度调整；这里只提供文案，没有代为发布。

> 我把正在使用的「回南天电影海报工坊」开源了。
>
> 换一张自己的照片，改导演署名，就能导出电影海报；也做了可以左右拖动的电影相册。现在有《生日快乐》和《浪花儿》两个分支，照片在浏览器本地处理。
>
> 项目用原生 HTML / CSS / JavaScript 和 Canvas，下载后不需要配置数据库或 API Key。欢迎第一次贡献开源的朋友一起写：英文快速开始、键盘操作体验、相册素材检查，都有独立的小任务。
>
> 想做后台的朋友也欢迎先讨论：下一步希望能管理影片名称、封面和排序。
>
> 先玩：https://poster.southwardfilm.cn/
>
> 代码：https://github.com/Wangnilong/southwardfilm-poster
>
> 选任务：https://github.com/Wangnilong/southwardfilm-poster/issues

## 配一段什么演示

录一段简短的真实操作：左右拖动选电影 → 换照片 → 改署名 → 导出成品。画面用自己的照片或已经获得许可的图片，最后同时放体验地址和仓库地址。

## 发出去之后

- 把需求拆成可以独立完成的小任务，注明文件位置和验收方式。
- 有人提问或提交 PR 时，及时给出具体回复；暂时不能处理也说明当前状态。
- 合并后在发布记录中感谢贡献者，并展示这次贡献改善了什么。
- 管理后台先讨论需求，再拆任务；不把未确定的大功能标成新手任务。

README、贡献指南和新手标签有助于参与者找到入口，参考 [GitHub 社区文件说明](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/about-community-profiles-for-public-repositories) 与 [新贡献者任务标签](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/encouraging-helpful-contributions-to-your-project-with-labels)。演示方式与文案是针对这个项目的建议，不代表会获得固定流量或贡献数量。
